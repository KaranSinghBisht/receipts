# Bob task session summaries

Screenshots of the Bob task sessions behind this submission, one per task.

Naming follows the hackathon guide's convention:

    receipts_taskNN_short_description_summary.png

To capture one: Bob IDE → **Tasks** (use **All** to see tasks across workspaces)
→ select the task → select the task header → screenshot the task session
consumption summary. PNG for text clarity.

The tasks themselves are the eight study runs in `corpus/bob/`, the requirements
extraction, and the parallel triage run — every one of them is a real Bob task
against the `ibm-coding-challenge-uat` instance.
